# Security policy

ZeroCue is pre-release software that performs privileged USB driver operations.
Do not use public issues to report a vulnerability that could affect users or
expose sensitive device data. Use GitHub's private vulnerability reporting or a
private security advisory for the repository instead.

Include the ZeroCue version, Windows version, connection mode, and the smallest
set of steps needed to reproduce the problem. Remove usernames, absolute paths,
serial numbers, device instance identifiers, and unrelated log content before
attaching diagnostics.

Only the latest published alpha is intended to receive security fixes during the
test period. This policy can be expanded after the first public release.
